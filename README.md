# 어디다 버려? — 그림 위에서 배우는 분리배출 AR

등록된 학습 그림을 비추면 그 위에 3D 모형이 나타나고, 분리배출 준비 과정을 단계별로 보여주는 Unity 프로젝트입니다.

- **그림 인식 → 그림 위의 3D 모형 → 이전·다음 단계 → 배출 안내 확인**
- 페트병: 전체 보기 → 뚜껑 열기 → 라벨 제거 → 몸통 압착 후 뚜껑 다시 닫기
- 배달 용기: 전체 보기 → 뚜껑 분리 → 오염 확인 → 배출 준비
- 그림을 놓치면 모형을 숨기고, 같은 그림을 다시 비추면 보던 단계부터 이어집니다.
- 이미지 AR 대상은 **페트병·배달 용기 그림 2종**입니다. 별도로 59품목 검색·상태 질문·개인 메모를 사용할 수 있습니다.
- Unity **6000.3.22f1**, AR Foundation/ARKit **6.3.5**, 실제 아이폰·아이패드 실행을 기준으로 합니다.

[업데이트·실행 순서](START_HERE.md) · [프로젝트 구조와 발표 설명](Docs/PROJECT_STRUCTURE.md) · [배출 안내의 근거와 범위](Docs/catalog-sources.md)

학습 그림은 [AR_TEST_CARDS.pdf](AR_TEST_CARDS.pdf)에 있습니다. 그림 전체 가로는 **12cm**를 기준으로 등록합니다. 그림 속 물체만 잘라 비추거나 임의의 실물 페트병을 비추는 방식이 아닙니다.

기존 버전은 사용자 iPad Air 11형(M3), iPadOS 26.5에서 설치·실행을 확인했습니다. 이번 이미지 AR 수정본의 Unity/Xcode 빌드, 실제 이미지 추적과 모형 표시는 기기에서 확인해야 합니다. 이 개발 환경에서는 Unity Editor와 Xcode를 실행하지 않았습니다.
