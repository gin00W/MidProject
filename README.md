# Chess FirstMove — 체스판 위에서 배우는 처음 배치와 이동법

처음 체스를 배우는 사람이 출력한 게임판 위에서 말의 위치와 이동 방향을 바로 비교할 수 있도록 만든 이미지 인식 AR입니다. 설명서의 좌표를 실제 칸에 옮겨 읽는 수고를 줄이는 것이 목적입니다.

- **출력한 체스판 인식 → 해당 칸 위에 3D 말·이동 예시 표시**
- 처음 배치: 판 방향 → 흰 폰 → 흰 뒷줄 → 검은 폰 → 검은 뒷줄
- 이동법: 폰·룩·나이트·비숍·퀸·킹의 기본 이동, 막힌 칸과 잡기 예시
- 판을 놓치면 표시를 숨기고, 다시 비추면 보던 학습 단계를 유지
- 맥북에서는 별도의 3D 미리보기로 조작 확인
- Unity **6000.3.22f1**, AR Foundation/ARKit **6.3.5**

[시작·실행 순서](START_HERE.md) · [체스판 PDF](Docs/ChessAR/ChessBoard.pdf) · [종이 말 PDF](Docs/ChessAR/PaperPieces.pdf) · [구조와 발표 설명](Docs/ChessAR/README.md)

체스 소스만 필요한 경우 [ChessAR-Starter.zip](ChessAR-Starter.zip)을 사용할 수 있습니다. 체스 코드·출력물·공용 SUIT 글꼴을 포함하며 기존 분리배출 런타임은 포함하지 않습니다. 기존 프로젝트를 사용하고 있다면 새 브랜치로 전환하는 방식이 설정을 재사용하기 편합니다.

현재 브랜치는 **`codex/chess-ar-learning-20261031`**입니다. 체스 소스·장면은 `Assets/ChessAR`에 분리되어 있으며, 기존 분리배출 브랜치 `codex/seongbuk-ar-starter-20261022`는 유지합니다. `Chess AR` 메뉴로 체스 장면을 준비하고 **새 iOS 출력 폴더**를 사용합니다.

보드게임을 살 필요 없이 A4 체스판과 종이 말을 출력해서 시연할 수 있습니다. 등록 대상은 테두리·좌표를 포함한 **A4 전체 그림 21 × 29.7cm**입니다. PDF를 실제 크기 100%로 인쇄하면 중앙 체스판은 17.6cm, 한 칸은 2.2cm입니다.

이 앱은 예시 배치에서 기본 이동을 배우는 도구입니다. 실제 종이 말의 위치를 인식하거나 경기의 합법 수·체크메이트를 판정하지 않습니다. 체크·캐슬링·앙파상·승격은 현재 학습 범위에서 제외합니다.

순수 C# 체스 규칙·학습 상태 검사 **35개**가 통과했습니다. 이 개발 환경에서는 Unity Editor와 Xcode를 실행하지 않았으며, 이번 체스 앱의 렌더링·실제 이미지 추적·기기 빌드는 실행 후 확인해야 합니다.
