# SUIT font source

The current application UI uses the unmodified static OpenType fonts below.
These are two separate weights, not a variable font or synthetic bold.

- Publisher: Sun / SUNN
- Official project: https://github.com/sun-typeface/SUIT
- Publisher page: https://sun.fo/suit/
- Distribution tag: `v2.0.5`
- Embedded font version: `Version 2.040;Glyphs 3.2.3 (3260)`
- License: SIL Open Font License 1.1, full copyright notice and license in `SUIT-LICENSE.txt`

The regular and semibold files have 11,437 Unicode cmap mappings each. Existing Nanum Gothic and Pretendard files are retained for older project assets; the current UI selects SUIT explicitly.
